LIQUIDITY+ BOT — STAGE 3: USER CONFIRMATIONS

Добавлено:
- Кнопки под каждым сигналом: «Беру», «Наблюдаю», «Пропускаю».
- Счетчики ответов обновляются прямо в клавиатуре.
- Один пользователь = один актуальный выбор; выбор можно изменить.
- Голосовать могут только получатели конкретного сигнала.
- Таблица signal_user_actions создается автоматически в signals.db.
- Админ-команда: /signalvotes ID

Пример:
/signalvotes 125

Команда показывает количество и процент пользователей в каждой категории.
